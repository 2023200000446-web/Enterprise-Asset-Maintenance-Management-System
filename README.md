# Asset and Maintenance Management System

A relational database project for managing company assets, employees, departments, vendors, asset assignments, maintenance requests, and maintenance records using Oracle SQL and PL/SQL.

## Project Overview

The **Asset and Maintenance Management System** is designed to store and manage information about:

- Employees
- Departments
- Roles
- Assets
- Asset Categories
- Vendors
- Maintenance Requests
- Maintenance Records
- Asset Assignments

This project demonstrates practical database concepts including table creation, primary keys, foreign keys, data insertion, SQL operators, set operators, joins, grouping, aggregate functions, subqueries, and views.

---

## Database Structure

The project contains the following 9 tables:

1. `Department`
2. `Role`
3. `Asset_Category`
4. `Vendor`
5. `Employee`
6. `Asset`
7. `Maintenance_Request`
8. `Maintenance`
9. `Asset_Assignment`

# How to Run the Project

## Step 1: Choose an Oracle SQL Environment

This project uses **Oracle SQL**, so the code should be executed in an Oracle-compatible environment.

You can use:

- Oracle SQL Developer
- Oracle Live SQL
- OneCompiler with Oracle SQL support
- Any other Oracle Database environment

For beginners, **Oracle SQL Developer** or an Oracle-compatible online compiler is recommended.
